# STEP – Step Towards an Effective Project

Statická webová stránka študentského tímového projektu STEP. Projekt robia štyria študenti
2. ročníka na UCM v Trnave v rámci predmetu Tímový projekt. STEP je webová aplikácia, ktorá
pomáha tímom plánovať a sledovať prácu na projekte.

Stránka je napísaná len v čistom HTML a CSS.

## Štruktúra súborov

```
index.html            úvodná stránka (vízia, misia, náš tím)
motivacny-list.html   motivačný list
zapisnica.html        zápisnice zo stretnutí
harmonogram.html      harmonogram projektu
o-aplikacii.html      popis aplikácie STEP
css/style.css         spoločný CSS súbor pre všetky stránky
img/                  logo a fotky členov tímu
dokumenty/            PDF dokumenty (motivačný list)
README.md             tento súbor
```

## Ako stránku otvoriť

- **Lokálne:** dvojklik na `index.html` – otvorí sa v prehliadači.
- **GitHub Pages:** v repozitári *Settings → Pages* zvoľ vetvu `main` a priečinok `/ (root)`.
- **Webhosting:** nahraj všetky súbory a priečinky (napr. cez FTP) do koreňového priečinka webu.

Všetky odkazy sú relatívne, takže stránka funguje všade bez úprav.

## Čo treba doplniť

- `img/logo.png` – logo tímu
- `img/clen1.jpg` až `img/clen4.jpg` – fotky členov tímu (v poradí kariet na úvodnej stránke)
- `dokumenty/motivacny-list.pdf` – PDF verzia motivačného listu
- všetky miesta označené textom `[DOPLNIŤ]`
